📖 2.1 知识精讲与课本例题

初二已学正整数指数幂的五条法则：aᵐ×aⁿ=aᵐ⁺ⁿ，aᵐ÷aⁿ=aᵐ⁻ⁿ，(aᵐ)ⁿ=aᵐⁿ，(ab)ⁿ=aⁿbⁿ，(a/b)ⁿ=aⁿ/bⁿ (b≠0)。现在把指数推广到零和负整数：

• 零指数幂：a0 = 1 (a ≠ 0)
• 负整数指数幂：a-n = 1 / an (a ≠ 0，n 为正整数)
• a-1 就是 a 的倒数；(a/b)-n = (b/a)n
⚠️ 注意：00 没有意义；零的负整数指数幂也没有意义。有了这两个定义，整数指数幂都适用上面五条法则。
💡 课本例题（化为分数）

(c) −7-2 = −1/72 = −1/49　(d) (−2)-4 = 1/(−2)4 = 1/16

(−7)-2 与 −7-2 不同：前者底数是 −7，后者是 7 的幂再取负。

计算 (2/3)-2 = 1/(2/3)2 = 9/4。

📖 2.2 知识精讲与课本例题
• a1/n = na (a > 0，n 为正整数且 n > 1)
• am/n = (na)m (a > 0，m、n 为正整数且 n > 1)
• a-m/n = 1 / am/n = 1 / (na)m
⚠️ 0 的正分数指数幂等于 0，0 的负分数指数幂没有意义。当 m、n 是分数时，五条运算法则仍然成立。

📖 2.4 知识精讲与课本例题
• 定义：aⁿ = x ⇔ loga x = n (a > 0，a ≠ 1，x > 0)；a 叫底数，x 叫真数
• 常用对数：以 10 为底，log10 x 写成 lg x
• loga a = 1，loga 1 = 0
• 积：loga(xy) = loga x + loga y
• 商：loga(x/y) = loga x − loga y
• 幂：loga xᵐ = m·loga x
⚠️ 零与负数的对数没有意义。log₃32 ÷ log₃16 ≠ log₃(32/16)，它等于 5/4（先把 32=2⁵、16=2⁴ 拆开）。
💡 课本例题（已知 lg2 = 0.3010，lg3 = 0.4771）

lg 6 = lg 2 + lg 3 = 0.7781　lg 30 = lg 3 + lg 10 = 1.4771

lg (2/3) = lg 2 − lg 3 = −0.1761　lg 0.5 = lg 1 − lg 2 = −0.3010

log81 9：设 x = log81 9，则 81x = 9，92x = 9，x = 1/2。
