3.1 正整数与负整数

在日常生活中，我们常遇到具有相反意义的量。例如：小明去银行存款RM100，小芳去银行提款RM100。虽然数额相同，但意义相反。

具有相反意义的量，可用符号 "+"（读作正）与 "－"（读作负）表示。像 3、5、12 这些数叫做正数；像 -3、-5、-10 这些在正数前加上负号的数叫做负数。

赚与赔、上与下、东与西、前进与后退、收入与支出、左与右、胜与负等，在数学上都可以用 "+" 与 "－" 来区别。

注意：正数的正号常省略不写，例如 +15 可写成 15；但负数的负号一定要写，不可省略。
例题
早餐店上个月赚了 RM10000，记作 +RM10000，那么这个月亏了 RM5000 记作什么？
解：亏了 RM5000 记作 －RM5000。

3.2 数线

我们可以用数线来表示正数与负数。画一条直线，取一定点作为基准点，称为原点，表示 "0"。规定由原点往右为正向，往左为负向。

自原点向右每隔一单位长取一点，依次表示正数 1, 2, 3, 4, …；自原点向左每隔一单位长取一点，依次表示负数 -1, -2, -3, -4, …。这条表示数的直线叫做数线（数轴）。

1, 2, 3, 4, … 称为正整数（也称自然数）；-1, -2, -3, -4, … 称为负整数。正整数、负整数与零统称为整数。

3.3 整数的比较

5 比 1 大，而数线上的 5 在 1 的右边。对于任意两数 a 与 b，若在数线上 a 的对应点在 b 的对应点右边，就说 a 比 b 大，记作 "a > b"；也可记作 "b < a"，读作 "b 小于 a"。

正数大于 0，负数小于 0，正数大于一切负数。
例题：比较大小
(a) 3 与 -5　(b) -2 与 -7　(c) 0 与 -4
解：(a) 3 > -5　(b) -2 > -7　(c) 0 > -4

3.4 相反数与绝对值

如果两个数只有符号不同，那么其中一个数叫做另一个数的相反数，两数互为相反数。例如，3 的相反数是 -3；-5 的相反数是 5；0 的相反数是 0。

在数线上，一个数所对应的点与原点的距离，叫做该数的绝对值。

正数的绝对值是它本身；负数的绝对值是它的相反数；0 的绝对值是 0。
例题：求绝对值
(a) |+5|　(b) |-3|　(c) |0|
解：(a) |+5| = 5　(b) |-3| = 3　(c) |0| = 0

3.5 整数的加法

同号两数相加：取相同的符号，把绝对值相加。
异号两数相加：取绝对值较大的数的符号，用较大的绝对值减去较小的绝对值。
一个数同 0 相加，仍得这个数。
例题
(a) (+3) + (+5)　(b) (-2) + (-7)　(c) (+6) + (-4)　(d) (-8) + (+5)
解：(a) +8　(b) -9　(c) +2　(d) -3

3.6 整数的减法

减去一个数，等于加上这个数的相反数。即　a － b = a + (－b)
例题
(a) 5 － 8　(b) (-3) － (-5)　(c) 4 － (-6)　(d) (-2) － 3
解：(a) -3　(b) +2　(c) +10　(d) -5

3.7 整数的乘法

两数相乘：同号得正，异号得负，把绝对值相乘。任何数与 0 相乘，积仍为 0。
多个不为 0 的数相乘：负因数有奇数个时，积为负；负因数有偶数个时，积为正。
例题
(a) (-3) × (-4)　(b) 5 × (-6)　(c) (-2) × (-3) × (-4)
解：(a) +12　(b) -30　(c) -24

3.8 整数的除法

两数相除：同号得正，异号得负，把绝对值相除。0 除以任何一个不等于 0 的数都得 0。
注意：0 不能作为除数。
例题
(a) (-12) ÷ (-3)　(b) 18 ÷ (-6)　(c) (-20) ÷ 5
解：(a) +4　(b) -3　(c) -4

3.9 乘方

求 n 个相同因数 a 的积的运算叫做乘方，结果叫做幂。an 中，a 叫做底数，n 叫做指数。

正数的任何次幂都是正数；负数的奇次幂是负数，负数的偶次幂是正数。
例题
(a) 2³　(b) (-3)²　(c) (-2)³
解：(a) 8　(b) 9　(c) -8

3.10 数列

按一定次序排列的一列数称为数列。数列中的每一个数都叫做这个数列的项。找数列的规律，通常从相邻两项的差或倍数关系入手。

例题：找规律
(a) 2, 4, 6, 8, ___, 12　(b) 1, 3, 6, 10, ___, 21
解：(a) 10（偶数数列）　(b) 15（三角形数）
