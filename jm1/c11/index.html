11.1 比与比例的概念及其性质

1. 比的概念与基本性质

数 $a$ 除以数 $b$ ($b$ ≠ $0$)，记为 $a : b$。$a$ 为前项，$b$ 为后项。

比值 $\frac{a}{b}$ 通常化为最简分数或最简整数比。

⚠️ 注意陷阱：

1. 同乘或同除以 $m$ ($m$ ≠ $0$)，比值不变：$a:b = ma:mb$。但 $(a+m):(b+m)$ ≠ $a:b$！

2. 比较不同单位时必须先统一单位（如 $150 \text{ 分钟} : 3 \text{ 小时} = 150 : 180 = 5 : 6$）。

2. 连比与比例性质

连比：三个量 $x, y, z$ 的比记为 $x : y : z$。（注意：连比不可写成分数形式）

比例基本性质：若 $a : b = c : d$，则：

$ad = bc$ （交叉相乘相等）

若 $a:b:c = x:y:z$，则存在非零常数 $k$，使得：$a = kx, b = ky, c = kz$

💡 课本经典例题解析

【例题1】 求 $150 \text{ 分钟}$ 与 $3 \text{ 小时}$ 的比值。
解：统一单位：$3 \text{ 小时} = 180 \text{ 分钟}$。
$150 : 180 = \frac{150}{180} = \mathbf{\frac{5}{6}}$。
【例题2】 已知 $y:z = 4:3$，$x:z = 7:6$，求 $x:y:z$。
解：公共项 $z$ 的最小公倍数 $\text{LCM}(3, 6) = 6$。
$y:z = 8:6$，$x:z = 7:6 \Rightarrow \mathbf{x : y : z = 7 : 8 : 6}$。

11.2 比例分配

什么是比例分配？

把一个数量按照一定的比例分成若干部分，叫做比例分配。

解法一（份数法）：
总比例 $a : b : c$，总份数 $S = a + b + c$。
各部分占总量的分数分别为 $\frac{a}{S}$, $\frac{b}{S}$, $\frac{c}{S}$。
解法二（常数 k 法）：
设各部分分别为 $ak, bk, ck$。
根据已知代数条件（如已知总和或已知两项之差）列方程求解 $k$。
【例题1】 将 RM 65,000 分给三兄弟，长:次 = 3:4，次:幼 = 2:3，求各自所得。
解：求连比：长:次:幼 = $3 : 4 : 6$，总份数 = $13$。
长子 = $65000 \times \frac{3}{13} = \mathbf{\text{RM } 15,000}$
次子 = $65000 \times \frac{4}{13} = \mathbf{\text{RM } 20,000}$
幼子 = $65000 \times \frac{6}{13} = \mathbf{\text{RM } 30,000}$
【例题2】 甲乙丙分钱，比为 6:5:2。若甲比丙多 RM 240，求款项总额。
解：设三人为 $6k, 5k, 2k$。
甲比丙多 $6k - 2k = 4k = 240 \Rightarrow k = 60$
总额 = $(6+5+2) \times 60 = 13 \times 60 = \mathbf{\text{RM } 780}$。

11.3 正比例与反比例

1. 正比例 (Direct Proportion)

若两相关联量变化时，它们的比值 (商) 固定，则成正比。

$\frac{y}{x} = k \text{ (常数)} \Rightarrow \mathbf{x_1 : x_2 = y_1 : y_2}$

例：速度固定时距离与时间；单价固定时数量与总价；地图比例尺。

2. 反比例 (Inverse Proportion)

若两相关联量变化时，它们的乘积固定，则成反比。

$x \cdot y = k \text{ (常数)} \Rightarrow \mathbf{x_1 : x_2 = y_2 : y_1}$

例：路程固定时速度与时间；工程总量固定时人数与天数。

【正比例例题】 桥长 $800\text{m}$，地图比例尺 $1:50000$，图上长多少 $\text{cm}$？
解：$800\text{m} = 80000\text{cm}$。设图长 $x \text{ cm}$。
$1 : 50000 = x : 80000 \Rightarrow x = \frac{80000}{50000} = \mathbf{1.6 \text{ cm}}$
【反比例例题】 工程 5 人做 16 天完成，若 4 人做需几日？
解：人数与天数成反比，乘积固定。
$5 \times 16 = 4 \times x \Rightarrow x = \frac{80}{4} = \mathbf{20 \text{ 天}}$
