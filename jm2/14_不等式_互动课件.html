第 14 章 不等式

初一学过用不等号表示两个数不相等。这一章要学会：不等式的基本性质、找出满足不等式的所有数（解集）、用不等式解决生活中的“最多／至少”问题。

📚 怎么学这一章？

  1. 读每一节的要点，在实验台里拖一拖、改一改，自己观察规律。
  2. 做随堂练习：5 道选择题，题目和选项每次都随机生成，选项还会打乱。
  3. 答对 3 题或以上，解锁 2 道作答题，要自己输入答案才算对。
  4. 学完四节后，到章末测验做综合随机题，看看哪一节还要加强。
💡 选择题里的错误选项，都是常见的算错结果（忘记变号、移项没变号、边界值取错……），所以要先自己算出答案再选，不要靠“一眼排除”。页面右上角可以切换深浅色、调整字体大小。

14.1 不等式的基本性质

拖动滑块、选择运算，观察不等号什么时候会“翻转”。

性质 1（加、减）

两边都加上或减去同一个数，不等号方向不变。

若 a < b，则 a ± c < b ± c

性质 2（乘、除正数）

两边都乘以或除以同一个正数，不等号方向不变。

若 a < b，c > 0，则 ac < bc

性质 3（乘、除负数）⚠️

两边都乘以或除以同一个负数，不等号方向必须改变。

若 a < b，c < 0，则 ac > bc

⚠️ 三个常见陷阱：① 乘（除）以负数忘记变号；② 乘以 0 时两边变成相等，不再是不等式；③ 只有“乘除”才会变号，“加减”永远不变号（如 a < b 推出 3 − a > 3 − b 是因为中间乘了 −1）。

14.2 一元一次不等式

解法和解方程几乎一样，只多了一条：乘除负数要变号。

  1. 去分母：两边同乘各分母的最小公倍数，每一项都要乘（包括不含分母的项）。
  2. 去括号：括号前面的数要乘进每一项；括号前是负号，括号内各项都变号。
  3. 移项：含未知数的项移到一边，常数项移到另一边，移项要变号。
  4. 合并同类项，化成 ax ○ b。
  5. 系数化为 1：两边除以 a；若 a < 0，不等号改变方向。

解集在数轴上怎么画？

带“=”（≥、≤）→ 实心点（边界也是解）；不带“=”（>、<）→ 空心圈（边界不是解）。

14.3 一元一次不等式组

先分别解出每个不等式，再取它们解集的公共部分（交集）。

口诀情形例子
同大取大都是“大于”x > 1 且 x ≥ 4 → x ≥ 4
同小取小都是“小于”x < 1 且 x < 4 → x < 1
大小小大中间找夹在两数之间x > 1 且 x < 4 → 1 < x < 4
大大小小无处找没有重叠x ≤ 1 且 x > 4 → 无解
口诀只是帮助记忆，遇到边界值相同（如 x ≥ 3 且 x ≤ 3）或一个带“=”一个不带时，一定要在数轴上画出来再判断。

14.4 应用问题

把生活里的限制条件翻译成不等式。

关键词不等号
至少、不少于、不低于、达到≥
最多、不超过、不高于≤
超过、高于、大于>
不足、低于、少于<
  1. 审题：圈出“最多／至少／超过”等关键词，统一单位（如 RM 与仙）。
  2. 设未知数：设要求的量为 x。
  3. 列不等式：把限制条件写成不等式。
  4. 解不等式，别忘了乘除负数要变号。
  5. 检验并取整：人数、件数等必须是整数。
⚠️ 取整规则：“最多能……”→ 解出 x ≤ 11.1 时取 11（向下取整）；“至少需要……”→ 解出 x ≥ 5.6 时取 6（向上取整）。如果是严格不等号（> 或 <）且边界值刚好是整数，边界值本身不能取。
