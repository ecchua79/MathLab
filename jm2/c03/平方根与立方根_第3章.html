3.1 平方根与算术平方根及其性质

平方根定义

如果 x2 = a (a ≥ 0)，那么 x 就叫做 a 的平方根（二次方根）。记作 ±√a。

算术平方根

正数 a 的正平方根叫做算术平方根，记作 √a。0 的算术平方根是 0。

⚠️ 易错警示与核心性质

  • 正数有两个平方根，它们互为相反数；负数没有平方根。
  • （√a）2 = a (a ≥ 0)。
  • √a2 = |a|（开出来的结果永远是非负数）。
几何直观：正方形面积与边长关系

已知面积求正边长为算术平方根；而平方等于25的数有两个：5 和 -5。

3.2 数的立方根及其运算

立方根定义

如果 x3 = a，那么 x 就叫做 a 的立方根（三次方根）。记作 3√a。

立方根的唯一性与符号性质

  • 任何实数都只有一个立方根。
  • 正数的立方根是正数；负数的立方根是负数；0 的立方根是 0。
  • 负号移到根号外：3√−a = −3√a。

3.3 有理数与无理数（实数分类）

有理数 vs 无理数

有理数：能写成分数形式 pq 的数（有限小数或无限循环小数）。

无理数：无限不循环小数。例如：√2, π, 0.1010010001...

数轴与实数

实数与数轴上的点是一一对应的。每一个无理数都可以用数轴上的具体几何位置精准表示。

几何构造：数轴上找到 √2

以 0 为圆心、斜边长 √2 为半径画弧，交数轴于 √2 对应的点。

3.4 二次根式的化简

积与商的算术平方根公式

√ab = √a · √b (a ≥ 0, b ≥ 0)

√ab = √a√b (a ≥ 0, b > 0)

最简二次根式的两大条件

  1. 被开方数中不含能开得尽方的因数或因式。
  2. 被开方数不含分母（分母中不含根号）。
图形拆解：√12 = √(4 × 3) = 2√3

面积 12 的正方形 = 4 个面积 3 的小正方形，所以边长 √12 是小正方形边长 √3 的 2 倍。
