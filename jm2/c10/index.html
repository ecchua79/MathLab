10.3 知识重点

三个集合联集的基数公式 (容斥原理)

对任意三个有限集 A, B, C，其联集公式为：
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) - n(A ∩ B) - n(A ∩ C) - n(B ∩ C) + n(A ∩ B ∩ C)

压轴难点突破

交集与联集的最大值与最小值探究

课本第 103 页 (练习 10.1a 第 4、5 题) 与 114 页常见考试压轴题：
当只有 n(A) 和 n(B) 给定时，交集 n(A ∩ B) 与联集 n(A ∪ B) 的可能范围界限。

设定基本集合大小

理论公式法则：

1. 交集最大值 max n(A ∩ B) = min(n(A), n(B))（小集合完全包含于大集合中）

2. 交集最小值 min n(A ∩ B) = max(0, n(A) + n(B) - n(ξ))（两集合尽可能拉开）

3. 联集最大值 max n(A ∪ B) = min(n(ξ), n(A) + n(B))

4. 联集最小值 min n(A ∪ B) = max(n(A), n(B))
